Discovery question

A lookup table gives the token Apple one vector, the same in every sentence it appears in. In “Love Apple Phones” a reader knows at once that Apple is a company. Where, in a system that owns only that table, is that knowledge?

Keep it in mind. You do not have to answer it yet.

Practical case

A product-search team represents each query by its token embeddings. This is their embedding space, flattened to two dimensions. The grey dots are catalogue items. Select a token to see its nearest catalogue items.

Nearest to Apple: …

For “Love Apple Phones”, the nearest catalogue items to the vector of Apple are fruit. A developer fixes it this way: each token's vector is replaced by the plain average of the three token vectors.
