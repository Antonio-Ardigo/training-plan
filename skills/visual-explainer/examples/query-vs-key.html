Query vs Key

Two weight matrices do the same job in the formula. Does training treat them the same? Predict first, then look at the numbers.

    The setup

    Three tokens, two dimensions. Each token asks a question with its query and is found by its key. The weight matrices WQ and WK start as exact copies of each other.

    negativezeropositiveTap or hover a cell to see where it comes from.
    In S and P, row i belongs to the token that asks, column j to the token that is asked.

    Your prediction

    WQ and WK are identical now, and the score table S is symmetric. We take one gradient step on the loss. Afterwards, are WQ and WK still identical?

    A score sits in row i because token i asked, and in column j because token j was asked. The query gradient reads the table by rows. The key gradient reads the same table by columns.

    The picture

    This is dS, the gradient of the loss with respect to each score. S was symmetric. dS is not, because softmax normalises each row separately.

    dQ = dS · K / √d    dK = dST · Q / √d. The transpose is the whole difference.
